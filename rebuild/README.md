# MATH Foundation 0.1

Чистая Android-основа для возобновления MATH Client. **Minecraft пока не запускает.**
Старый `app/` и ветки Stage/parity не изменены. Новый Gradle-проект живёт
целиком в `rebuild/`; package `com.balzikz.mathclient.foundation` устанавливается
рядом со старым MATH и Minecraft.

## Что уже реализовано

- Чтение установленного `com.mojang.minecraftpe`: точная версия, versionCode,
  APK-подписи, base APK, все `splitSourceDirs`, nativeLibraryDir, Activity/Service metadata.
- SHA-256 APK и всех обнаруженных `.so`; заголовки ELF и ABI; счётчики assets/DEX.
  Чтение потоковое: библиотека размером сотни мегабайт не помещается целиком в RAM.
- Диагностическое окно в отдельном процессе `:probe`, загрузка собственной
  `libmathprobe.so` через JVM и проверяемый `RegisterNatives`.
- Собственный EGL/OpenGL ES 2.0 кадр: зелёная левая половина, тёмная правая.
  `PROBE_SWAP_OK` означает только успешный `eglSwapBuffers` нашего теста,
  не игровой кадр, не GameActivity parity и не доказательство показа пользователю.
- Append-only JSONL-журнал с session/PID/TID/process/временем; старые сессии не очищаются.
- Java stack trace; история завершений Android 11+; native tombstone при наличии
  в Android 12+. OS может уже не хранить trace — это явно отражается в отчёте.
- Просмотр, полное копирование небольшого текста, ZIP через FileProvider,
  выбор старой сессии. Ограничение Clipboard не приводит к незаметному усечению.
- 28 автономных тестов ядра; отдельный CI для APK/lint и эмуляторного JNI/EGL теста.

## Чего пока нет

Нет загрузки `libminecraftpe.so`, Java/JNI-контракта конкретной версии Bedrock,
DT_NEEDED/dynsym-разбора в Android-приложении, объединённого AssetManager,
GameActivity bridge, копирования runtime, client hooks или модулей.
Наличие и корректный SHA APK **не означают** совместимость хоста.

Чужие APK, декомпилированные классы и бинарники не включаются в сборку/репозиторий.
Не нужны root, общий доступ к хранилищу, overlay, сеть или изменение Minecraft.
Никаких обходов авторизации, лицензии или защит в этом этапе нет.

## Собрать и проверить

Требования: JDK 17, Gradle 9.4.1, Android SDK 36 / build tools 36.0.0,
NDK 27.0.12077973, CMake 3.22.1. AGP 9.2.1 закреплён как в старом проекте.
Gradle Wrapper пока не включён; команды ниже требуют установленного Gradle.

Из корня репозитория:

```bash
bash rebuild/tools/test-core.sh
gradle -p rebuild :core:regressionTest :app:lintDebug :app:assembleDebug
```

APK: `rebuild/app/build/outputs/apk/debug/app-debug.apk`.
Сборка включает arm64 для телефона и x86_64 для эмулятора. CI использует
существующий тестовый ключ репозитория, чтобы повторные APK устанавливались как обновления.
Ключ отладочный, не для production-публикации.

## Короткая проверка на телефоне

1. Установить новый APK рядом со старым клиентом. Не удалять и не обновлять Minecraft для эксперимента.
2. Открыть **MATH Foundation**, нажать **Обследовать Minecraft** и дождаться завершения.
   На большом APK SHA-256 может считаться заметное время.
3. Нажать **Проверить JNI и графическое окно**. Зафиксировать, видны ли обе половины поля.
4. Вернуться кнопкой, нажать **Поделиться сессией ZIP** и приложить ZIP в чат.
   При ошибке вернуться/открыть приложение снова; сессия остаётся доступной.

ZIP включает технические пути/версии и иногда native trace. Перед отправкой
проверить содержимое: native trace может содержать сведения о памяти процесса.
В Foundation не загружается Minecraft и не запрашиваются игровые токены.
Полные native `.pb` не отображаются текстом; они доступны только в ZIP.
Сессии и экспорты сохраняются до очистки данных/удаления **Foundation** пользователем.

## Следующий рубеж

Получить реальный отчёт устройства, зафиксировать точный набор установленной игры.
Затем проверить Java/native GameActivity контракт именно этого набора и добавить
минимальный host-adapter. Первый игровой кадр требует отдельного подтверждения.
Исторические версии 1.26.30.5 и 1.26.31.1 — факты старых опытов, не требования
к текущей установке и не список поддерживаемых версий.

Подробности восстановления: [ARCHAEOLOGY.md](ARCHAEOLOGY.md).
